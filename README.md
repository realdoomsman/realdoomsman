### Dooms

I build onchain products end to end: Solana and Robinhood Chain launchpads, the programs and contracts underneath them, trading systems, and the tooling that keeps them running.

**Stack:** TypeScript · Rust / Anchor · Solidity · Python · Next.js · Node · Postgres / SQLite

---

#### Launchpads and protocols

| Project | What it does |
|---|---|
| [loaded](https://github.com/realdoomsman/loaded) | Solana launchpad on pump.fun where every coin gets an onchain vault that defends a floor price |
| [moshsol](https://github.com/realdoomsman/moshsol) | Holdfast: backers fund the pump.fun launch buy, held in an agent-run onchain vault |
| [mirror](https://github.com/realdoomsman/mirror) | Launchpad where each coin funds an onchain vault that copy-trades a public wallet |
| [vise](https://github.com/realdoomsman/vise) | Time-weighted lock-to-earn vaults for pump.fun coins (Anchor program, SDK, app) |
| [pudlpudl](https://github.com/realdoomsman/pudlpudl) | Permissionless DLMM liquidity protocol on Solana |
| [pomp](https://github.com/realdoomsman/pomp) | One memecoin launched on pump.fun (Solana) and Pons V2 (Robinhood Chain) at once |
| [stockpile](https://github.com/realdoomsman/stockpile) | Pons V2 memecoins on Robinhood Chain whose creator fees pay holders in tokenized stocks |
| [lev](https://github.com/realdoomsman/lev) | Pons V2 coins whose fees fund an onchain leveraged treasury that buys back and burns |
| [clasp](https://github.com/realdoomsman/clasp) | Lock Pons memecoins and earn their trading fees in ETH |
| [bellwether](https://github.com/realdoomsman/bellwether) | Memecoin creator fees trade US-stock perps, with a receipt for every burn |
| [vantra](https://github.com/realdoomsman/vantra) | Launchpad where each coin's fees keep an AI agent alive; it buys back and burns with what it earns |
| [runway](https://github.com/realdoomsman/runway) | Buy an AI agent whose payment becomes a custodied Solana treasury |
| [vouch](https://github.com/realdoomsman/vouch) | Routes onchain creator fees into verified fundraisers, with receipts |
