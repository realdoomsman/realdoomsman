### Dooms

I build onchain products end to end: Solana programs and EVM contracts, the APIs, keepers and indexers around them, and the apps people use. Most of my work is DeFi infrastructure, trading systems and AI agents that hold and spend real money.

**Stack:** TypeScript · Rust / Anchor · Solidity / Foundry · Python · Next.js · React · Node · Postgres
