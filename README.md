### Dooms

I build onchain products end to end: Solana and Robinhood Chain launchpads, the programs and contracts underneath them, trading systems, and the tooling that keeps them running.

**Stack:** TypeScript · Rust / Anchor · Solidity · Python · Next.js · Node · Postgres / SQLite

---

#### Launchpads and protocols

| Project | What it does |
|---|---|
| [imagine](https://github.com/realdoomsman/imagine) | IMAGINE ([imagine.fun](https://imagine.fun)): lock-to-earn launchpad on Raydium LaunchLab. Lock a coin, earn its trading fees in the pair asset. OtterSec-verified Anchor program, SDK, API and app |
| [pyre](https://github.com/realdoomsman/pyre) | Launchpad where each coin funds an app |
| [mirror](https://github.com/realdoomsman/mirror) | Launchpad where each coin funds an onchain vault that copy-trades a public wallet |
| [stockpile](https://github.com/realdoomsman/stockpile) | Pons V2 memecoins on Robinhood Chain whose fees pay holders in tokenized stocks |
| [lev](https://github.com/realdoomsman/lev) | Pons V2 coins whose fees fund an onchain leveraged treasury that buys back and burns |
